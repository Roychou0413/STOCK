# STOCK — 倉庫盤點掃描

手機用的倉庫盤點網頁：掃條碼（或輸入條碼／品名）→ 選狀態與數量 → 寫入 Google 試算表。

## 檔案
| 檔案 | 說明 |
|---|---|
| `index.html` | 前端網頁（單一檔案） |
| `apps-script/Code.gs` | Google Apps Script 後端 |
| `manifest.webmanifest`、`sw.js`、`icon-*.png` | PWA：可加到主畫面、離線也能開啟 |

## 功能
- 相機掃條碼、手電筒、掃到時有提示音和震動
- 直接輸入條碼數字，或用品名、型號搜尋
- **連續模式**：每掃一次，指定狀態就 +1，不跳視窗
- **查無條碼**：可新增商品，或把條碼綁到已有的商品上
- 本次紀錄可**撤銷**；斷網時寫入先**暫存**，恢復連線後自動上傳
- 全部庫存：有**快取**，可依試算表順序、儲位或品名排序；可篩選 未盤／已盤／盤盈／盤虧，顯示進度條，並可匯出報表
- **盤點人員**：會記在試算表上，每次寫入也會記一筆到「異動紀錄」工作表
- **儲位**：可在商品視窗直接編輯

## 後端部署（更新 Code.gs）
1. 打開試算表 → 擴充功能 → Apps Script，用 `apps-script/Code.gs` 的內容**整個取代**原本的程式。
   （建議先把舊程式另存備份）
2. 確認 `CONFIG.COLS`、`CONFIG.STATUSES` 的標題名稱和你的試算表一致。
3. 部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「**新版本**」→ 部署。這樣網址不變，前端不用改。
4. （強烈建議）專案設定 → 指令碼屬性 → 新增 `API_TOKEN` = 自訂密碼。
   然後在每支手機網頁右上角的「⚙ 設定」輸入同一組存取碼。
   ⚠ 存取碼不要寫進 `index.html`，因為這個 repo 是公開的。

### 試算表欄位
後端依**標題列文字**找欄位，欄位順序不限：
- 必要：`品名`、`國際條碼`，以及各狀態欄（`新品`、`福利品`、`瑕疵`、`報廢`、`樣品`、`採購樣品`）
- 選用：`型號`、`帳面數量`（有這欄才會顯示盤盈、盤虧）
- 自動新增：`儲位`、`最後盤點時間`、`盤點人員`，以及「異動紀錄」工作表

### 盤點規則
- 「⚙ 設定 → 開始新一輪盤點」會記下開始時間。之後有寫入過的商品算「已盤」，其餘算「未盤」。
  開始時可以選擇把數量歸零，系統會先自動複製一份備份工作表。
- 差異 = 所有狀態數量合計 − 帳面數量。
